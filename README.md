## نظام العُهد (docs/)

موقع ثابت يعمل عبر GitHub Pages لرفع ملفات العهدة بعد التصفية ومعالجتها تلقائياً:

- **رفع عهدة**: اسحب ملف Excel (كل ورقة = شركة) ليعرض البنود ويحسب إجمالي كل بند وكل تصنيف والإجمالي الكلي.
- **تنزيل الملف المعالج**: يصدّر Excel بنفس القالب المعتمد (البيان، التصنيفات، الإجمالي، صف المجموع، سطر التوقيعات).
- **إنشاء عهدة جديدة**: نموذج لإدخال البنود وتصديرها بنفس القالب، مع تنزيل قالب فارغ.
- **الأرشيف**: العهد المرفوعة تُحفظ محلياً في المتصفح (localStorage) — لا تُرسل أي بيانات لأي خادم.
