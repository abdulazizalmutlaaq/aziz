اسحب ملف العهدة هنا أو اضغط للاختيار ملف Excel (xlsx / xls) — كل ورقة تمثل شركة، بنفس قالب العهدة المعتمد

إنشاء عهدة جديدة بنفس القالب

أضف شركة أو أكثر، ثم أدخل البنود واختر التصنيف والمبلغ. عند التصدير ينشأ ملف Excel بنفس أعمدة قالبك مع الإجماليات محسوبة.

أرشيف العُهد

العهد المرفوعة تُحفظ محلياً في متصفحك (localStorage). لا تُرسل بياناتك لأي خادم.

يعمل هذا الموقع بالكامل داخل المتصفح — لا يتم رفع أي بيانات إلى الإنترنت.
